zot continuous Sandbox control

This deployment provides an authenticated control API at /api.

  • GET /api: inspect the sandbox.
  • POST /api: start the host.
  • DELETE /api: delete the sandbox with explicit workspace-loss confirmation.

All API requests require the administrator bearer token. Do not paste secrets into this page.

Use the returned Sandbox WebSocket URL with your compatible zot client. See the repository README for setup, credentials, and lifecycle limitations.
